# Online-Retail-Transaction-Dataset



## Project Overview

This project analyzes an online retail sales dataset using SQL to understand customer purchasing behavior, product performance, and sales trends.

The dataset contains transactional records from an online retail store, including product details, customer information, purchase quantities, prices, and transaction dates. By applying SQL queries, the project explores business questions such as top-selling products, highest revenue-generating countries, customer purchasing patterns, and sales performance over time.

## Dataset Description

The dataset represents an online retail company's sales transactions. Each row represents an individual product purchase within an invoice.

The main columns include:

- InvoiceNo: Unique transaction identifier
- StockCode: Product identification code
- Description: Product name
- Quantity: Number of items purchased
- InvoiceDate: Date and time of transaction
- UnitPrice: Price per item
- CustomerID: Unique customer identifier
- Country: Customer's country

## Objectives

- Analyze total sales and revenue performance
- Identify best-selling products
- Find countries generating the highest revenue
- Understand customer purchasing behavior
- Analyze monthly and yearly sales trends
- Explore product demand patterns
